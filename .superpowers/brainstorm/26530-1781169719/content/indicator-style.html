A — Animated color dots

Evolves the existing dot: green pulse = working, amber glow-pulse = waiting, solid green = done, dim = idle, hollow = exited. Minimal change to current visual language.

B — Status glyphs

Distinct icon per state: spinner = working, blinking "?" = waiting, check = done. Readable without relying on color alone (color-blind friendly), but busier.
