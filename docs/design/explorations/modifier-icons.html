The consistency gap

The previous comparison matched the wrapper settings, but that does not make the paths a consistent family. Filled paths bypass stroke width and line joins. Different occupied areas, corner radii, and detail density also change perceived weight.

Proposed direction: stroke-built utility icons on the existing 16×16 grid, rounded 1.5-unit strokes, and shared geometry for related frames. Check optical weight at 12, 14, and 16 px; equal numeric settings alone are not enough.

KEEP PURPOSEFUL DIFFERENCES

Provider logos retain their authored geometry and brand colors. Play/Stop, selected stars, and status dots may retain purposeful fills. Tiny dots and compact task marks should be judged in context, rather than forced into hollow outlines.

Suggested direction

Use A for macOS: ⌃ and ⇧ alongside the current ⌘. Use C for Windows and Linux: Ctrl and Shift. Keep the full key names in accessible descriptions; a Control caret should never serve as a standalone action icon.

Render modifier icons in a fixed slot with a 4 px gap. Keep shortcut hints quiet, right aligned, and separate from the action label. These are static hint specimens, not working application controls.

Source context: Command is used by Settings → View shortcuts. Sidebar hints currently use ⌘1/2 on macOS and Ctrl+Shift+1/2 elsewhere. The current checkout also contains a Shift outline; A reuses its exact path. B and the Control caret are exploratory paths.

Exploratory HTML, not a measured native reference. Implementation adopts the recommended Control caret and existing Shift outline in application shortcut hints, preserving keybindings. Other proposed icon redesigns remain exploratory. Linux sidebar, shortcut reference, and input context menus were inspected in an isolated app; macOS/Windows rendering and live Codex/Claude behavior remain untested.
