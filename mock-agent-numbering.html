What changes in code: the number slot goes into header_row (view.rs:1590), between Space::with_width(Fill) and the zen/kill buttons — rendered only for tile positions 0..9. The value is tile_order position + 1, matching select_visible_session(n) (update.rs:1791).
  • A · muted digit — quietest; reuses existing header text style (mono, FG_MUTE). Lowest visual noise but reads as data, not a key.
  • B · kbd chip — outlined chip; clearly "a key". Turns cyan on the focused tile. Recommended default.
  • C · accent chip — cyan-tinted; most scannable but louder across a full 4×4 grid.
  • D · ⌘ icon + digit — shipped. Real ⌘ SVG glyph (rendered via the icon sprite, so no font dependency) + the digit on macOS; falls back to ctrl+shift+N text on other platforms.
