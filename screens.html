A4 is selected. The compact app-header dropdown keeps the nested Project > Worktree > Session model and the full content width.

Review the whole path before implementation. Workspace switches restore remembered content, local setup errors stay in their forms, and session processes keep running until a person closes them.

Behavior rules

  • Switching restores the target workspace's last session or its closest scoped landing state. Sessions in other workspaces keep running.
  • Escape or an outside click closes an overlay without changing state. Focus returns to the trigger.
  • A selected worktree's hover icons direct-start the chosen agent. The last-used agent can remain the first option.
  • Project import accepts local Git repositories only. Worktree success reveals a row and never starts a session.
  • List and Project keep the scoped hierarchy. Grid hides the hierarchy sidebar so active sessions own the canvas, while selection stays attached.
  • Destructive actions confirm. Nonempty workspace deletion is blocked. Closing a running session warns that its process stops while the worktree remains.
