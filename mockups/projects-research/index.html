These are exploratory visual directions, not native implementations or usability-test results. Names, paths and session counts are fixtures.

What informed the options

GitHub Desktop: managing worktrees groups main and linked worktrees and displays the directory and branch. Option C explores that distinction; B uses aligned branch names across projects.

Apple: disclosure controls recommends keeping commonly used controls visible and revealing details when relevant. A and E explore different disclosure boundaries.

GOV.UK: accordions cautions that people may miss hidden content and recommends testing against a simpler visible page. That is a tradeoff to test in A and E.

Apple: layout describes using spacing, containers and separators to communicate relationships. The directions apply those tools at different densities. These references are precedents, not proof that a direction will perform better for Grove.
