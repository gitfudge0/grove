Sidebar width is fixed at RAIL_W = 320. Background bg-rail; footer button is a flat outlined "+ add project" that fires AddProject. The agent menu overlay (split-button caret) is rendered as a stack! sibling positioned by row offset.

Tree header hosts a single toggle. When anything is expanded beyond the active chain, it shows the collapse-all glyph — clicking closes everything except the chain leading to the active worktree (its project stays expanded, the active worktree stays expanded so its sessions remain visible). Once collapsed, the same button flips to the expand-all glyph; clicking opens every project and worktree. If there is no active worktree, collapse closes everything.
