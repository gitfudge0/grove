Header "+" combo — replacing the session-launcher FAB

Today, opening the session launcher happens via a floating circular + pinned to the bottom-right of the agent grid. This moves it into the top header as a two-button combo welded to the agent-view (grid) toggle. The + appears only in agent view — leave grid view and it collapses back to the lone grid toggle. Flip the switch to see the two states; three combo styles below.

Agent (grid) view
ON — combo shows the +
Variation A · segmented combo (recommended)
grove

One rounded control, hairline divider between segments. The + reads as the primary launch action; the grid segment keeps its cyan "active" fill. Feels like one object, minimal added chrome — closest to the existing appbar language.

Variation B · distinct buttons, magenta ring on the +
grove

Keeps the + visually tied to the old FAB (magenta 1px ring) so the muscle memory of "the magenta circle adds a session" carries over. Two separate hit targets rather than one grouped control.

Variation C · primary + (filled magenta) fused to toggle
grove

Most prominent: the + is a filled magenta chip — the loudest "new session" affordance. May be too heavy for a persistent header element; strong if launching sessions is the dominant action.

Side by side · both states (Variation A)

Agent view — ON

combo: + | grid

The launcher lives right where the eye already goes to toggle views. No floating element over your terminals.

Agent view — OFF

grid only

Outside the grid there's nothing to launch into, so the + collapses away. The grid toggle stands alone, muted.
