B2The rulesPROPOSED

Ten decisions that collapse the drift. Each one is checkable in review.

UMModal — normative rules

One line each. If a surface can't follow a rule, it needs a documented exception (there is currently exactly one).

  • Width by content class: SM 420 sentence-only · MD 480 form / short list · LG 560 rows with a secondary column · XL 640 scrolling list or palette. AgentPicker→480, ThemePicker→560 per this rule.
  • One header component with slots (meta, subtitle, step). Close X always present, except blocking-progress states.
  • One overflow strategy: body max-height 456 + scroll. Row-windowing and uncapped bodies removed.
  • One footer: no strip fill — a 1px border-soft divider over a transparent py 8 row on the rail. Hints left in mono 10, buttons right, always secondary → affirmative. Hints-only modals are the same row minus the button group.
  • esc hint vocabulary: exactly "cancel" (abandons input), "close" (nothing to lose), or "back" (returns to parent). Nothing else.
  • The left footer slot retires. Hints occupy that position. Former left-slot content moves into the body as a flat tinted text action (AgentPicker's "Set as default"), or into the header meta slot (Settings' version string). Dismiss-only modals: a single "Close", Primary, always.
  • No bordered buttons inside bodies — in-body actions are flat tinted text buttons.
  • One field: strip fill, radius 6, 1px border-soft, px 10 / py 7. Focus = 1px magenta border + a 2px magenta-tinted outer ring. The bare field_underline contract retires. Launcher search zone: headerless, borderless input on the rail — the one sanctioned exception.
  • One boxed-group recipe: card = radius 4 + border + strip fill. Groups-of-controls radius 6. Panel radius 12. Nothing else.
  • One focus / selection language: magenta = keyboard focus, cyan tint + ring = selection. The yellow agent ring is retired.
  • Shadow becomes a theme token — the light theme gets a lighter, tighter shadow instead of the same 40px black drop.
