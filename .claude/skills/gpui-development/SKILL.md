# GPUI development

Read [development guidance](../../../product/development.md) before changing
GPUI mechanics or answering an API question from memory. It identifies the
pinned source owners and validation approach; inspect their current signatures
instead of copying old snippets.

For product behavior, start with the [product index](../../../product/README.md).
For native UI implementation, review or screenshot work, also follow the
[Grove UI skill](../grove-ui/SKILL.md) and its design contract and interaction checks.
Compile borrowed patterns against the current checkout; reading an upstream
example does not establish compatibility or native behavior.
