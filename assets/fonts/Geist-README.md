# Geist Sans

Official static TrueType fonts from [vercel/geist-font](https://github.com/vercel/geist-font/tree/10dc7658f13c38a474cde201bb09a4617267545b/fonts/Geist/ttf), commit `10dc7658f13c38a474cde201bb09a4617267545b`. Downloaded without modification on 2026-10-02.

Bundled faces: Regular (400), Medium (500), SemiBold (600), Bold (700). Registered family: `Geist`. Static fonts avoid requiring variable-font support from the native text system.

License: SIL Open Font License 1.1; see `Geist-OFL.txt`. Geist is used throughout the non-PTY interface. BlexMono retains the PTY font and cell metrics.
