# Bundled application fonts

DM Sans: Google Fonts repository commit `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`, `ofl/dmsans/DMSans[opsz,wght].ttf`. Static TrueType faces instantiated with fontTools at optical size 14 and weights 400, 500, 600, 700; family/subfamily name records normalized to DM Sans and each weight. See DMSans-OFL.txt.

JetBrains Mono: official stable release v2.304, JetBrains/JetBrainsMono repository commit `cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`, `fonts/ttf/`; unmodified Regular, Medium, SemiBold, Bold, Italic, BoldItalic faces. See JetBrainsMono-OFL.txt.

Downloaded 2026-10-23. DM Sans is the UI family; JetBrains Mono is the monospace family. JetBrains Mono has advance 600/1000 em, giving 7.5 pixels at the terminal's 12.5 pixel font size. Platform glyph fallback remains available for characters absent from these fonts.
