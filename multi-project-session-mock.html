E1Context roots popover

The neutral linked-roots trigger works with every variant. It lists exact project and branch or worktree pairs.

E2Narrow overflow stress

Long names collapse with an explicit count. Header and rail card do not wrap or grow.

E3Ordinary single-project session

No linked-roots marker appears when a session has one context root.

Primary cwdThe first selected root remains the primary cwd: portfolio / main. Additional roots describe context, not a new working directory.
What the marker counts“3 projects” means three context roots. It is not a subprocess, terminal, pane, or agent count.
Interaction boundaryNothing here implies project switching. A details popover may explain roots, but it does not navigate or change the active worktree.
